# Contador de Fluxo de Pessoas

Sistema simples para contagem de pessoas usando YOLO.

## Como usar

Execute o arquivo `executar.py`:
```bash
python3 executar.py
```

**Importante**: O sistema criará automaticamente um ambiente virtual na primeira execução.

## Controles

- **ESC** ou **Q**: Sair
- **ESPAÇO**: Pausar/Retomar vídeo
- **F**: Alternar tela cheia

## Dependências

O sistema instalará automaticamente:
- ultralytics (YOLO)
- opencv-python (CV2)
- lap (tracking)
